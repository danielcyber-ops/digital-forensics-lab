# Digital Forensics Lab

A hands-on digital forensics laboratory documenting practical investigations, forensic workflows, tools, and techniques.

This repository contains my learning journey and practical work in digital forensics, with an emphasis on evidence acquisition, preservation, examination, analysis, and reporting.
